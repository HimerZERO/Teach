# Система аксиом Цермело-Френкеля с аксиомой выбора

### Аксиома объёмности
$$\forall AB(\forall x(x \in A \leftrightarrow x \in B) \to A=B)$$
Обратное следует из аксиомы предиката = ($\forall AB (A=B \to (\varphi[A] \to \varphi[B]))$)

### Аксиома пустого множества

$$\exist \emptyset \forall x (x \not\in \emptyset)$$

Аксиома показывает, что существует пустое множество

***
***Определение***
Множество $I$ называеися индуктивным, если
$$\left\{\begin{array}{l} \emptyset \in I\\ x \in I \to x \cup \{x\} \in I\end{array}\right.$$
***
### Аксиома бесконечности
Существует индуктивное множество.

***Замечание***

### Аксиома пары
$$\forall A_1 \forall A_2 \exist B \forall x (x \in B \leftrightarrow x = A_1 \lor x = A_2)$$
Аксиома показывает, что для любых твух множеств существует множество, содержащее только их как элементы, иначе говоря существует неупорядоченная пара для любых двух множеств

### Аксиома множества подмножеств

$$\forall A \exist D \forall S (S \in D \leftrightarrow S \sub A)$$

Для любого множества существует множество состоящие из всех подмножеств изначального
